% Size: about 15.7 cm x 6.6 cm (fits 0.95\textwidth of A4 with 2 cm margins; height <= 7 cm).

% Suggested caption (the numbers are the circled step markers):
%   Cloud architecture and request path. (1) CloudFront serves the SPA from a private S3 bucket
%   (OAC). (2) Users sign in on the Cognito hosted UI (code + PKCE); the SPA sends the ID token.
%   (3) POST /workshops/{id}/commands passes the HTTP API JWT authorizer. (4) The api Lambda
%   writes CMD#{commandId} = ACCEPTED with a conditional Put and (5) enqueues the command on
%   commands.fifo (message group = workshopId), answering 202. (6) The worker, the only writer
%   of a workshop, reads the live items with a consistent Query and runs decide() (tick-first);
%   (7) it sends one TICK per new offer to the expiry-delay queue (DelaySeconds <= 900 s)
%   before (8) committing one TransactWriteItems guarded by the META version. (9) The browser
%   polls GET /commands/{id} (consistent read) until the command is APPLIED or REJECTED.
%   (10) A due timer is moved by the expiryForwarder into the workshop's FIFO group. (11) Every
%   5 min a sweep queries the sparse DUE index and enqueues a TICK for overdue workshops
%   (safety net, not on the latency path). (12) New notifications reach the notifier through
%   DynamoDB Streams and are sent through SES. Solid arrows: requests; dotted black: the 202
%   reply; dashed: queued messages and timers; dotted grey: the sweep's index query.
