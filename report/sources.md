# Sources register for the Final report

Each key in `report/references.bib` is listed here with its URL, access date, page date (when the page shows one), how it was verified, and the claim it supports. "Accessed" is the date the page was opened for this register. Market-sizing figures and their derivations are in `docs/market-sizing.md` §2.

Verification levels:

- **fetched**: page downloaded; the quoted statement was read in the downloaded text.
- **own count**: entries counted on official pages downloaded on the access date.
- **official excerpt**: the page is on the publisher's own domain, but direct download was blocked (bot protection, HTTP 403, or client-side rendering). The statement was read from the search engine's excerpt of that page. These need a dated browser screenshot before submission.
- **Crossref**: published paper; bibliographic data and DOI checked against `api.crossref.org` on 2026-10-17.
- **resolves**: page opened (HTTP 200) and its title checked. Cited as the human-readable home of figures that were read elsewhere, such as the AWS Price List API.

How pages were retrieved: `curl` from the build environment, plus web search for pages that block automated download. The pages behind the own counts (one LibCal day list per day and campus, the three NTU directory pages) are committed unmodified under `results/market/2026-10-17/raw/` with a `capture.json` log (URL, HTTP status, bytes, UTC time); `tools/market/capture.py` fetched them and `tools/market/count.py` counts them into `results/market/2026-10-17/counts.json` and `summary.md`, from which `report/tools/report_numbers.py` writes the `\Market…` macros. For the LibCal counts, the script requests `…/ajax/calendar/list?c=-1&date=YYYY-MM-DD&perpage=100&page=1&audience=&cats=&camps=&inc=0` for each day, which is the request the public calendar page makes.
