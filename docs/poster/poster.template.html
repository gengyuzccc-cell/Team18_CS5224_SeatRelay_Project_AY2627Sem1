SeatRelay

One waitlist for every session of a workshop.

Register once and rank the sessions you can attend. When a seat frees up, it is held for the next person in line automatically, instead of staying empty or waiting for an organiser’s e-mail.

2How it works

  1. Tick every session you could attend and put them in order.
  2. Wait in one queue. When a seat in one of your sessions frees up, it is held for you (15 min by default).
  3. Accept, decline or let it expire: the seat moves on to the next person at once.
  4. Organisers see every hand-over and its delay.

Screens of the deployed app in a staged run with test accounts (1-minute holds).

3What runs on AWS

  • One lane per workshop. Requests for one workshop are decided one at a time, so they never race; different workshops run in parallel.
  • All or nothing. Seats, queue, offer and notice change in one database transaction.
  • A timer for every hold. Expiry is judged by server time, so a late or repeated timer cannot touch a newer offer.
