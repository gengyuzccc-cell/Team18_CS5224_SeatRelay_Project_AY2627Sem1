# Submission checklist (deadline: 13 Nov 2026)

**Prototype scope update (2026-10-31):** the team decided on 2026-10-31 to deliver a simulated
interview/usability-study package. That package is complete in [research](research/README.md), with
explicitly synthetic source records, raw responses, analysis and charts; the report and slides
state its generation method. The historical field-study commitments below are retained as empirical
work, not marked complete by simulated data. No real interview, recruitment or pilot is claimed.

Every action that remains before `Final.pdf` and `Slides.pdf` are submitted, with the owner role and the
file each action changes. Owners are the Preliminary report's work lines; the names in brackets follow
the assignment in `docs/ai-declaration-drafts.md`, approved by the team on 2026-10-24.

Rules that apply to every row:

- **No invented data.** Interview, study and pilot numbers come only from the files named below, and only
  after the event really happened. A short or small sample is reported as it is (Prelim §5).
- **Staged is labelled staged.** Rehearsed or scripted activity (for example
  `results/<date>-pilot-rehearsal/`) is logged and reported separately from natural pilot events, everywhere
  it appears.
- **Student numbers** stay in the git-ignored `report/team-ids.tex`; only the submission build
  (`./report/build.sh -t Final -m 10 -s`) prints them, into the git-ignored `report/Final-submission.pdf`.
- A team-evidence step (1.1, 1.4, 1.5) is done when its results file exists (`results/interviews/summary.md`,
  `results/pilot/`, `results/user-study/summary.md`) and `python3 -I report/tools/check_numbers.py` no longer lists
  its macros (`\InterviewN`, `\PilotWorkshops`, `\StudyParticipants`) as pending; `placeholders=0` alone does not
  show this, because those macros sit inside `\IfPending` and print "not yet run" text. Every other step is done
  when `./report/build.sh -t Final -m 10` still prints `pages<=10 overfull=0 undefined=0`.
